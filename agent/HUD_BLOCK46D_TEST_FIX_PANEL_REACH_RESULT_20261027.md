## 3) 커밋 C — 패널 후보를 "부대 + 표식 상자" 기준으로도

- **표식 스크립트** `reach_rect(id)`: 부대 화면 상자와 표식 두 부분을 합친 사각형이다. 표식이 숨으면 빈 사각형이다.
  - 부대 화면 상자는 발 점에서 좌우 1 m, 땅에서 2.4 m 높이다. `show_unit`이 받은 foot, body, cell_px로만 만든다. 1 m = cell_px / 3이고, 2.4 m는 몸통 점(1 m)을 2.4배 늘려 잡는다.
  - 새 엔진 읽기는 없다. 셸이 이것을 패널 상태 `"reach_rect"`로 넘긴다.
- **패널 `choose_position()` 순서** (단계 1·2와 점수 계산은 그대로):
  1. 2D 규칙이 고른 자리가 표식·HUD 둘 다 안 겹치면 그대로.
  2. 가까운 후보 8개(앵커 기준) 중 둘 다 안 겹치는 곳.
  3. **(새)** `reach_rect` 바깥 가장자리에서 `ANCHOR_GAP`(22 px) 떨어진 후보 8개(오른쪽·왼쪽, 위·아래, 대각선 넷). 화면 안으로 가두고, 둘 다 안 겹치는 곳 중 2D 점수가 가장 좋은 곳.
     - **3b (지시에 없던 보완)**: 그것도 다 막히면, 길을 막는 HUD 사각형(`reach_rect`나 그 후보와 겹치는 것) 하나씩과 `reach_rect`를 합친 상자의 둘레에서 같은 방식으로 찾는다.
  4. 모서리 후보.
  5. 이후는 그대로(표식만 피함 → 2D 자리).
  - 3은 1·2가 모두 막혔을 때만 계산한다.
- **3b를 넣은 이유** [사실]: 지시대로 3까지만 넣고 쓸림 시험을 돌렸다. 부대가 **아군 로스터 밑으로 들어가면**(줌 30 앵커 x 203, 줌 42 x 234 등) 3의 후보 8개가 모두 로스터(x 54–324)나 표식과 겹쳤다. 그래서 다시 모서리로 1,493 px 점프했다.
  - 로그로 확인했다: 후보 8개 각각이 로스터, 아군 로스터와 전투 기록, 또는 표식과 겹쳤다.
  - 3b를 넣으니 로스터 오른쪽(x 346)에 붙어서 점프가 사라졌다.
  - [추정] 지시서의 뜻(부대 곁을 따라감)에 맞는 최소 보완이다. 받아들일지는 아래 8)에 적었다.
- 패널은 이번 단계를 기록하는 값 두 개(`chosen_step`, `round_hud`)를 남긴다. 시험과 보고용이며, 배치에는 쓰지 않는다.
