## 2. 도시 내부창 — 성 그림만 (허용 파일: `worldmap_city_interior_controller.gd`, 위 두 테스트)
1. **제목줄 전체 삭제**: `TitleLabel`·`CloseButton`·`header`를 만들지 않는다. 창에는 `InteriorArea`(성 그림)만 남는다.
2. **"그림만"**: 창 `PanelContainer`의 패널 스타일을 빈 스타일(여백·테두리·배경 0)로 해서 창 모양 = 성 그림 모양이 되게 한다. 그림 크기(너비 = 도킹 너비, 높이 = 너비 × `BODY_ASPECT`)와 도킹 위치 규칙은 그대로. 창이 자기 위 클릭을 먹는 성질(PanelContainer 기본)은 유지.
3. 닫기 방법은 둘만: **ESC**(그대로) + **창 밖 빈 지도를 마우스 왼쪽으로 눌렀을 때**. 눌림을 `set_as_handled`로 삼키지 않는다(그 클릭이 원래 하던 일은 그대로 한다).
   - 닫히면 **안 되는** 것(눌러도 창이 유지): 창 자신, 좌측 패널(그립 드래그 포함), 오른쪽 패널, 위쪽 메뉴 버튼들, 턴 버튼, 도시 마커 클릭(기존 규칙대로: 내 도시면 그 도시로 바뀌고, 남의 도시면 닫힘).
   - "빈 지도"의 판정 방법은 클코드가 정한다(예: 눌린 위치의 맨 위 컨트롤이 HUD가 아님). 방법과 이유를 보고서에 쓴다. 지도 드래그(카메라 이동)로 닫히는지도 관찰해 보고서에 한 줄(닫혀도 이번엔 허용).
4. 도시 이름 안내 글자가 필요한 곳은 없다(오른쪽 패널에 이미 나옴). `PLACEHOLDER_TEXT`(성 레이아웃이 없는 도시용 안내 글자)는 **이번에 건드리지 않는다** — 보고서에 "레이아웃 없는 도시에서 창이 어떻게 보이는지" 한 줄만 적는다(김작 결정 대기).
5. API: `get_title_text()`·`get_close_button()`은 삭제한다(호출처 없음 확인 후). 새 접근자는 필요 최소한만.
6. 테스트 수정(승인): `test_worldmap_city_interior_window.gd`의 제목 검사(87·115행)는 "제목줄이 없다(`TitleLabel`·`CloseButton` 노드 없음) + `get_open_city_id()`가 맞는 도시"로 바꾸고, 닫기 버튼 `pressed.emit()`(120행)·layouts 86행은 `close()` 호출로 바꾼다. **검사를 약하게 만들지 말 것**(열림/닫힘 상태 확인은 그대로 유지).
7. 새 검사(같은 테스트 파일 또는 새 테스트 파일, 새 파일이면 `verify-c-track.yml` 목록 **끝**에 추가): ESC로 닫힘 / 창 밖 빈 지도 눌림으로 닫힘 / 창 위 눌림·좌측 패널 그립 눌림은 안 닫힘 / 도시 전환(내 도시→다른 내 도시)은 계속 동작 / 창 높이·너비가 `InteriorArea`와 같음(여백 0).

## 3. 턴 버튼 — 하늘/테두리 틈 원인 수정 (허용 파일: `scripts/worldmap/worldmap_turn_compass.gd`, 새 테스트 1개)
