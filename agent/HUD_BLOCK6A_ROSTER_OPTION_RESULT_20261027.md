## 0) 선행 조사 (코드 변경 전, 2D 원본 코드 기준)

1. **2D 로스터의 퇴각·전멸** [사실]
   - **2D에는 부대별 "퇴각" 상태가 따로 없다.** `is_alive()` = `current_hp > 0 and current_troops > 0`(`scripts/battle_unit_state.gd:234`)가 거짓이면 퇴각이자 전멸이다.
   - 전투 스크립트 전체에 "퇴각" 문자열은 없다(월드맵의 도시 메시지에만 있다).
   - 2D가 하는 일(`battle_web_import_test.gd:14095-14130` `_cleanup_dead_units`):
     - 화면 가운데에 토스트를 띄운다("후퇴한다! 훗날을 기약하겠다!" 등, `:341-360`).
     - 전투 기록에 "%s 전멸"을 남긴다.
     - 전장 부대를 숨긴다.
   - **펼친 2D 로스터에서 카드는 남고, 밝기는 그대로이며, 글자가 없다.**
     - 카드는 늘 보인다(`battle_hud_state_adapter.gd:69`).
     - 매번 `slot.modulate = Color.WHITE`로 되돌린다(`battle_web_import_test.gd:16048-16049`).
     - `action_state = "전멸"`은 값으로 있지만 그 라벨은 늘 숨겨진다(`battle_roster_hud_controller.gd:41`).
     - "병력 0 / N"으로 보인다.
   - **접은 2D 로스터**: 그 얼굴만 `Color(0.62, 0.62, 0.62, 0.72)`로 흐려지고 글자는 없다(`battle_roster_presentation_controller.gd:382-389`).
2. **2D 접기 깃발** [사실, `battle_roster_presentation_controller.gd`(`ProductionRosterCollapseExperiment`), `Battle_Production.tscn:4422-4442`]

     - 로스터 투명도가 0으로 간다.
     - 얼굴 기둥 투명도가 1로 간다.
     - 깃발이 (4,115) / (1856,115)로 옮겨 간다.
     - 끝나면 로스터를 숨긴다.
   - **펼치기**는 그 반대다(`:283-305`).

## 1) 커밋 A — 옵션창이 HUD에 가리지 않게

- 셸이 옵션창의 층을 `OPTION_LAYER = 20`으로 올린다(HUD는 5–10).
- 열 때마다 `option_box_position()`이 자리를 정한다.
  - x 후보: 버튼 아래, 또는 각 HUD 사각형의 바로 왼쪽.
  - y 후보: 버튼 줄 아래, 또는 각 HUD 사각형의 바로 아래.
  - 그중 화면 안에서 HUD 사각형과 겹치지 않는 것 가운데 버튼 아래에 가장 가까운 자리를 고른다. 없으면 버튼 아래에 두고, 층 덕분에 위에 그려진다.
- 1920×1080 결과: **(1379, 126)**, 상단 HUD 틀 바로 아래이자 적군 로스터 왼쪽이다. 크기는 210×130이다.
- 옵션창 크기는 라벨이 줄바꿈되므로, 최소 크기와 실제 크기 중 큰 것을 쓴다.
- 기존 동작은 그대로다: 옵션창의 접힘, AI 단계 버튼, 가장자리 스크롤 체크박스, 옵션창이 열려 있으면 가장자리 스크롤 꺼짐.
  - `option_ai_level`(29), `option_ai_level_auto`(9), `option_strategy_gaps`(5), `edge_scroll_gates`(14)는 **바꾸지 않고** 통과했다.
  - "드래그"는 옵션창에 없다. 지금 있는 동작이 접힘과 잠금뿐이라 그대로 두었다. [사실]
- **고친 이전 시험 1줄** [사실]: `test_battle3d_top_commands.gd:95`이 옛 x 1435를 그대로 비교했다. 지금은 "x ≤ 1435이고 적군 로스터의 왼쪽"을 본다. 검사 수 39는 그대로다.

## 2) 커밋 B — 로스터 퇴각 카드

- 셸 `ally_cards()` / `enemy_cards()`가 카드마다 `"retreated"`를 낸다. 표시값의 병력이 0 이하이면 참이다.
  - 카드 표시 = 부대 뷰가 보임 **또는** 퇴각.
  - 도착 전 증원은 병력이 있으므로 그대로 숨는다(N9 그대로).
- 로스터는 퇴각 카드를 다음처럼 보인다.
  - **흐림**: 카드 `modulate = (0.62, 0.62, 0.62, 0.72)`. 2D에 있는 유일한 퇴각 흐림 값이다. 지시서의 "시작값 알파 0.5·채도 낮춤" 대신 "2D와 같은 정도"를 따랐다(아래 8)).
  - **"퇴각" 글자**(2D에는 없어서 지시대로 "퇴각"): 카드 가운데 위에 30pt, 밝은 색, 테두리 6으로 얹는다. 카드의 자식이 아니라 형제 라벨이라, 흐림이 글자에 번지지 않는다.
- 선택 금테, 카드의 마우스 무시, 초상화 경로는 그대로다.
- **고친 이전 시험 1줄** [사실]: `test_battle3d_enemy_roster.gd:189`가 매 프레임 "카드 보임 = 부대 뷰 보임"을 비교했다. 퇴각 카드도 보이는 것으로 친다. 검사 수 39는 그대로다.
- 캡처 `_08`: 정도전과 관우 카드가 흐려지고 "퇴각"이 읽힌다. 다만 글자가 이름·병력 줄과 겹쳐 그 위에 얹혀 있다. [사실: 캡처]

## 3) 커밋 C — 로스터 접기 깃발 (2D 그대로)

- 새 `battle3d_roster_fold.gd`(Node)를 로스터마다 하나씩 두었다. 숫자는 모두 2D 코드·장면에서 왔고, 검증기가 2D 파일과 대조한다.
  - **깃발**: 2D 그림, `ProductionHudRoot` (350,121) / (1507,124), 60×126. 로스터 중 **유일하게 마우스를 받는 노드**다(층 5, 로스터와 같은 CanvasLayer).
  - **접기 / 펼치기**: 0.30초, cubic in-out. 로스터와 얼굴 기둥의 투명도, 깃발 자리 (4,115) / (1856,115)를 함께 바꾸고, 끝나면 로스터를 숨기거나 보인다. 전환 중 누름은 무시하고, 기본은 펼침이며, 이번 실행 동안만 기억한다.
  - **얼굴 기둥**: 72×72, x 8 / 1840, y 250 + 78 × 칸. 행동 장수는 카드의 금테가 뒤에 붙는다. 퇴각은 2D처럼 흐림 (0.62, 0.62, 0.62, 0.72)만 주고 글자는 없다. 접힌 동안에도 카드 값을 따라 갱신된다.
  - **턴 바뀜 펄스**: 셸이 아군 턴과 적군 턴이 바뀔 때 그쪽 깃발을 2D처럼 커졌다 돌아오게 한다.
- **접힌 사각형**: `roster_rect()`가 얼굴 기둥(테두리 포함)과 접힌 깃발을 합친 사각형을 낸다.
  - 아군 (1,117) 78×521, 적군 (1835,117) 78×521이다.
  - 셸 HUD 목록, 명령 패널, 카메라 가운데 맞춤이 이것을 쓴다.
- 가장자리 스크롤: 깃발 위에서는 마우스가 깃발에 잡혀 꺼진다(4-4 규칙). 접혀서 빈 옛 로스터 자리에서는 켜진다.
- **2D와 다르게 둔 것** [사실]:
  1. **얼굴 기둥은 3D 로스터가 보이는 카드만** 보인다. 2D는 도착 전 증원 2명도 흐리게 보인다(캡처 `twod_rosters_folded.png` 5명 대 3D `_03` 3명). N9를 이번에 바꾸지 않아서다.
  2. **아군 얼굴 클릭으로 선택하기는 넣지 않았다.** 2D는 엔진 명령 `_select_ally_unit`을 부른다. 3D에는 그 명령이 없고, 넣으면 새 엔진 호출이 된다(금지).
  3. **N8**(적 얼굴의 다음 행동 금테)은 없다(3D에 N8이 없음).
- **고친 이전 시험 1줄** [사실]: `test_battle3d_ally_roster_actor.gd:177`은 "로스터 노드 전부 마우스 무시"였다. 이제 깃발만 빼고 본다. 검사 수 104는 그대로다. 그 시험의 "로스터 아래 [대기] 버튼 실제 클릭"도 통과했다.
