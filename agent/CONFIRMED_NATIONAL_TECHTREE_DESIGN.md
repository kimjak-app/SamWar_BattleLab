# 삼국WAR 국가 테크트리 확정 설계 v1.0

---

## 기본 원칙

```
국가 테크트리 = 재상이 실행, 플레이어가 방향 선택
모든 도시에 적용 (도시 테크트리와 다름)

재상 적성 → 테크트리 방향 결정:
행정형(administrative) → 행정 계열
경제형(economic)       → 경제 계열
군정형(militaryAdmin)  → 군사 계열
외교형(diplomatic)     → 외교 계열
정치형(political)      → 감찰·첩보 계열
```

## 국가 테크트리 구조

```
기초
└─ 국가 기반 정비
   → 조건: 없음
   → 비용: 금전 200

   ├─ 행정 계열
   │  └─ 법률 정비
   │     → 조건: 행정형 재상
   │     → 비용: 금전 300 + 비단 100
   │
   │     ├─ 관료 체계
   │     │  → 조건: 법률 정비 완료 +
   │     │          보유 도시 2개 이상
   │     │  → 비용: 금전 500 + 비단 200
   │     │
   │     │  ├─ 지방 행정
   │     │  │  → 조건: 관료 체계 완료 +
   │     │  │          보유 도시 3개 이상 +
   │     │  │          태수 임명 도시 2개 이상
   │     │  │  → 비용: 금전 600 + 비단 300
   │     │  │
   │     │  │  └─ 중앙집권 ★
   │     │  │     → 조건: 지방 행정 완료 +
   │     │  │             행정형 재상 10턴 유지 +
   │     │  │             국가 충성도 70 이상 +
   │     │  │             보유 도시 5개 이상
   │     │  │     → 비용: 금전 1000 + 비단 500
   │     │  │
   │     │  └─ 감찰 제도
   │     │     → 조건: 관료 체계 완료 +
   │     │             정치형 재상
   │     │     → 비용: 금전 400 + 비단 200
   │     │
   │     │     └─ 부패 방지 ★
   │     │        → 조건: 감찰 제도 완료 +
   │     │                국가 충성도 65 이상
   │     │        → 비용: 금전 600 + 비단 300
   │     │
   │     └─ 호적 제도
   │        → 조건: 법률 정비 완료 +
   │                보유 도시 2개 이상
   │        → 비용: 금전 400
   │
   │        └─ 인구 조사
   │           → 조건: 호적 제도 완료 +
   │                   행정형 재상
   │           → 비용: 금전 500 + 식량 200
   │
   │           └─ 인구 정책 ★
   │              → 조건: 인구 조사 완료 +
   │                      보유 도시 4개 이상 +
   │                      민심 평균 70 이상

   │
   ├─ 경제 계열
   │  └─ 세제 개혁
   │     → 조건: 경제형 재상
   │     → 비용: 금전 400
   │
   │     ├─ 균등세
   │     │  → 조건: 세제 개혁 완료 +
   │     │          보유 도시 2개 이상
   │     │  → 비용: 금전 500 + 비단 100
   │     │
   │     │  └─ 화폐 통일
   │     │     → 조건: 균등세 완료 +

   │     │             경제형 재상 5턴 유지
   │     │     → 비용: 금전 800 + 철 200
   │     │
   │     │     └─ 국가 경제 ★

   │     └─ 전매 제도

   │        → 비용: 금전 600 + 비단 200
   │
   │        └─ 국가 전매 ★
   │           → 조건: 전매 제도 완료 +
   │                   경제형 재상 +
   │                   소금·비단 잉여 동시 보유

   │

   │  └─ 징병 제도
   │     → 조건: 군정형 재상

   │
   │     ├─ 군사 훈련령
   │     │  → 조건: 징병 제도 완료 +
   │     │          충성도 평균 60 이상
   │     │  → 비용: 철 200 + 금전 400 + 식량 300
   │     │
   │     │  ├─ 군사 개혁
   │     │  │  → 조건: 군사 훈련령 완료 +

   │     │  │          철 충분

   │     │  │  └─ 상비군 ★
   │     │  │     → 조건: 군사 개혁 완료 +
   │     │  │             충성도 평균 75 이상 +
   │     │  │             보유 도시 4개 이상 +
   │     │  │             철 1000 + 식량 1000
   │     │  │     → 비용: 철 800 + 금전 1000 +
   │     │  │             식량 800
   │     │  │
   │     │  └─ 병참 제도

   │        └─ 무기 공장 ★
```

## 각 테크 효과

```
국가 기반 정비   → 태수 임명 가능 도시 수 ↑
법률 정비        → 전국 민심 +5
관료 체계        → 태수 효과 +10%
지방 행정        → 도시별 세금 효율 ↑
중앙집권 ★       → 모든 도시 수입 +20% + 태수 효과 극대화
감찰 제도        → 금전 손실 감소
부패 방지 ★      → 세금 효율 극대화
호적 제도        → 징병 가능 인원 +10%
인구 조사        → 징병 효율 ↑
인구 정책 ★      → 전국 인구 성장 + 징병 한계 ↑

세제 개혁        → 전국 금전 수입 +10%
균등세           → 민심 ↑ (세금 불만 감소)
화폐 통일        → 무역 수입 +15%
국가 경제 ★      → 전국 금전 수입 극대화
전매 제도        → 소금·비단 독점 수입 ↑
국가 전매 ★      → 전략 자원 독점 → 금전 대폭 ↑

징병 제도        → 전국 징병 효율 +10%
군사 훈련령      → 전국 전투력 +10%
군사 개혁        → 전국 전투력 +20%
상비군 ★         → 전국 전투력 극대화 + 징병 속도 ↑
병참 제도        → 원정 보급 안정
원정 체계 ★      → 장거리 원정 가능 + 보급 손실 없음
무기 규격화      → 전국 전투력 ↑
무기 공장 ★      → 무기 대량 생산 → 징병 비용 ↓

사신 파견        → 외교 행동 가능
외교 체계        → 관계 개선 속도 ↑
동맹 체계        → 동맹 효과 강화 → 무역 수입 ↑
천하 외교 ★      → 전국 무역 극대화 + 외교 공작 가능
첩보 체계        → 적 정보 수집 가능
첩보 조직 ★      → 전국 첩보 활동 가능
조공 체계        → 비단으로 관계 개선 속도 ↑
조공 네트워크 ★  → 비단 외교 극대화 → 동맹 유지 비용 ↓
```

## 도시 테크트리와의 연결

```
국가 테크 완료 → 도시 테크 해금 조건에 사용:

화폐 통일 완료 → 조폐소 건설 가능
병참 제도 완료 → 건어물 보급기지 효과 강화
동맹 체계 완료 → 실크로드 조건 충족
첩보 조직 완료 → 적 도시 공작 가능
```

## 테크트리 시간 제한 (확정 — 수치는 미확정)

### ① 건설 시간 (턴 소요)
```
자원 투입 즉시 착공 → N턴 후 완성
(자원만 있다고 즉시 완성 아님)

등급별 건설 시간:
기초 테크  → 3~5턴
중급 테크  → 8~10턴
고급 테크  → 15~20턴
최고 ★     → 25~30턴

※ 정확한 턴 수는 수입 기준 밸런싱 후 확정
```

### ② 국가 테크가 도시 테크를 잠근다
```
고급 도시 테크는 국가 테크 완료 없이 해금 불가

국가 → 도시 잠금 매핑 (예시):
화폐 통일(국가) 완료 → 조폐소(도시) 해금
군사 개혁(국가) 완료 → 거북선·철갑보병(도시) 해금
동맹 체계(국가) 완료 → 실크로드(도시) 해금
병참 제도(국가) 완료 → 건어물 보급기지(도시) 해금
첩보 조직(국가) 완료 → 적 도시 공작 가능

※ 전체 매핑은 도시·국가 테크트리 확정 후 별도 문서로
```

### ③ 자원 수입 속도 = 테크 템포
```
테크 속도는 내정 수준에 달려있다:

수입 많으면 → 자원 빨리 축적 → 테크 빨리 투자 가능
수입 적으면 → 자원 느리게 축적 → 테크 느려짐

핵심 딜레마:
자원을 테크에 쓰면 → 군사에 못 씀
자원을 군사에 쓰면 → 테크가 느려짐
자원을 모병에 쓰면 → 테크·군사 둘 다 느려짐

→ 이게 삼국WAR 내정의 핵심 전략 선택

※ 현재 한성 기준 금전 ~70/턴
  테크 비용이 "몇 턴치 수입인지" 역산해서
  전체 테크 비용 밸런싱 필요 (별도 세션)
```
