### 1. 2D 자동 버튼 활성 규칙

- `_refresh_auto_battle_button_state(can_issue_ally_command)`:
  - 자동 중이면 항상 활성("자동중지")
  - 아니면 `can_issue_ally_command`일 때만 활성
  - `can_issue_ally_command` = `current_phase == ally_turn and not is_demo_animating and _is_active_ally_action_available()`
  - `_is_active_ally_action_available` = 활성 아군 있음, 살아 있음, 혼란·행동불가·공포 아님, 미행동
- 3D 활성 조건:
  - 시작: 기존 공용 안내 `_ally_command_block_reason("자동")`(전투 종료 / 적 턴 / 연출 / 재생 큐 / phase / 선택 없음 / 이미 행동)
  - 중지: 자동 중 언제든
  - 혼란 아군은 엔진 판정(`_is_active_ally_action_available`)을 3D가 읽지 못한다(읽기 미승인). 다만 엔진이 혼란 아군 턴을 바로 소비해서(`_consume_confused_ally_turn_if_needed`, ally_turn 진입 시 지연 호출) 실제로 그 상태에서 멈춰 있지 않는다.

### 2. 자동 한 스텝의 흐름과 이벤트

- 진입:
  - `_set_phase(ally_turn)`가 자동 중이고 연출이 없으면 `call_deferred("_tick_full_auto_battle_if_needed")`를 부른다.
  - 틱은 한도·생존·활성 아군을 확인한 뒤 `auto_battle_step_count += 1`, 그다음 `_run_auto_action_for_active_ally_once()`
  - 분기 순서: 처치 공격 → 고가치 특기 → 공격 → 이동 → 저가치 특기 → 대기
- 기본 배치·시드 1·라운드 3까지 스텝별로 새로 쌓인 이벤트를 셌다(이동 / 행동 / 전술 로그):
  - 이동: `ally_move_event_log` 3개(이동 후 방향은 엔진이 자동 선택). 바로 다음 스텝은 같은 부대의 "이동 후" 행동
  - 공격: `battle_action_event_log` 2개(`attack_resolved`, `action_completed`)
  - 특기: `tactic_event_log`(skill_cast / effect / finished)
- **아군 쪽 이벤트가 0개인 분기**:
  - **자동 대기**(`_auto_wait_active_ally` → `_end_ally_turn_by_wait`). 실측: 이동 후 대기, 이동 못 하는 증원의 대기
  - **혼란 아군 턴 소비**(`_consume_confused_ally_turn_if_needed`). 코드 확인. 상태 틱만 남을 수 있다
- 3D 처리(엔진 수정 없음):
  - 아군의 엔진 `has_acted`가 켜졌는데 그 사이 그 부대의 `action_completed` / `skill_cast` / `strategy_cast`가 늘지 않았으면, 전투 기록·상태줄에 "자동 · <부대> 행동 완료 (대기 또는 혼란: 엔진 이벤트 없음)"을 남긴다.
  - 둘을 구별하는 읽기는 승인되지 않아, 문구에 둘 다 적었다.
  - 이 처리는 자동 중(또는 자동이 막 끝난 프레임)에만 돈다. 수동 대기는 기존대로 "대기 · <부대>"다.

### 3. 안전 한도와 종료

- `_get_auto_battle_max_steps()`: 기본 배치에서 96(배치된 생존 유닛 × 계수, 최소·최대 사이).
- 한도에 닿으면 `_stop_full_auto_battle("자동전투 안전 제한 도달 …")`.
- **전투 종료**: `_handle_battle_end_guard`가 자동을 끈다(`[AUTO_BATTLE_STOP] reason=battle result finalized`).
  - 실측: 기본 배치를 자동으로 끝까지 돌리면 시드 1·2 모두 **라운드 11 패배**, 4배속에서 약 20초.
- 3D는 `is_full_auto_battle_enabled`가 true → false로 바뀐 것을 읽어 "자동 종료"를 보인다. 3D가 자동을 스스로 끄지 않는다(validator).

### 4. 중지 시점 동작

- 아군 행동 연출 중 중지: 그 행동은 끝까지 진행된다. 이후 수동 입력이 된다(테스트).
- **자동 이동 도중 중지**:
  - 엔진 `_stop_full_auto_battle`이 `_clear_auto_action_flags()`로 "이동 후 방향 자동 선택"을 지운다.
  - 그래서 그 부대는 **`facing_select`에서 멈춘다**(엔진의 정상 수동 흐름). 3D는 방향 버튼을 보여 주고, 확정하면 수동 턴이 이어진다.
  - 실측(적 재생 중 중지): jeong_dojeon이 facing_select, 3D 방향 UI 표시
- 3D `selected`·링은 매 동기화마다 엔진 `active_unit_state`를 따른다.
- 범위 표시는 자동 시작 때 지우고, 자동 중에는 3D가 새로 그리지 않는다. 중지 후 남은 표식 0개를 확인했다(테스트).

### 5. 입력 잠금

- 엔진이 자동 중 막는 것: `_can_use_strategy`가 false. 2D 명령 패널은 자동 중 숨겨진다.
- 3D:
  - `_input_locked()`에 자동 조건을 넣었다(전투 종료 다음, 적 턴 앞): "자동 진행 중 · [자동 ■]로 중지한 뒤 조작하세요"
  - 이 잠금이 클릭 선택·이동, 우클릭 취소, 방향, 공격, F 키, 대기, 방어, 책략, 특기를 막는다.
  - 공용 안내 `_ally_command_block_reason`에도 같은 줄을 넣어 버튼이 비활성으로 보인다. 공격 버튼은 별도 줄에 조건 하나를 추가했다.
  - 자동 버튼과 속도 버튼만 살아 있다.

### 6. 엔진 타이머

- `get_tree().create_timer(...)` 8곳이다: 특기 미리보기 0.42초, 효과 적용, 종료, 컷인 대체 신호, `await create_timer(delay)` 등.
  - `ignore_time_scale` 인자를 주는 곳이 없어 모두 `Engine.time_scale`을 따른다.
- Tween 33곳은 기본 시간 배율을 따른다.
- 엔진 `_process(_delta)`는 시간에 의존하는 규칙 계산이 없다. 3D `_process(delta)`, 적 재생 대기(`enemy_hold`), 라벨 Tween도 같은 배율로 빨라진다.

### 7. 속도와 결정성 — **같다**

- 같은 시드로 기본 배치 자동을 **1배속과 4배속**으로 돌렸다.
- 엔진 안에서 라운드 시작 때(`_start_new_round` 직후) 다음을 찍었다: 유닛 40필드, 기세, 로그 4개(순서 포함), 전투 로그 줄, 다음 전역 난수 값.
- 라운드 2·3·4 해시와 다음 난수 값이 모두 같았다(라운드 3: `0.0255569592118263`). 실시간은 25.5초 대 7.7초.
- 테스트(§7 `auto_speed`)에서 1x·2x·4x로 다시 확인했다.
- 전역 난수: 엔진의 `randf_range` FX와 `randi()`(음성 경로 선택)는 프레임 수가 아니라 사건 수만큼 소비되어 배율과 무관했다.

### 8. time_scale 원복

- 3D Lab에 `_exit_tree()`를 추가해 `Engine.time_scale = 1.0`으로 되돌린다.
- 4배속에서 랩을 닫은 뒤 1.0을 확인했다(테스트 4곳). 랩이 처음 만들어질 때도 1배속으로 설정한다(`_apply_speed`).

## 2. UI 상태

- 줄 y=300에 [자동 ▶](600,300)과 [속도 1x](760,300)를 두었다.
  - 같은 줄 왼쪽은 기존 방향 패널(24,300)이 쓰므로 오른쪽 칸을 썼다.
  - 다른 단계와 겹치지 않는다(M5-b는 별도 오버레이 노드).
- 자동 버튼 문구:
  - 대기 중: `자동 ▶`
  - 자동 중: `자동 ■ (중지)`
  - 시작 조건이 안 되면 비활성, 툴팁 없음(공용 안내 문구는 누르면 거절로 나옴)
- 속도 버튼은 `속도 1x` → `2x` → `4x` → `1x`로 돈다.
- 상태줄·전투 기록 문구:
  - 시작: `자동 진행 중 · 엔진이 행동을 선택합니다 / [자동 ■]로 중지`
  - 중지: `자동 중지 · 진행 중인 행동이 끝나면 수동 조작`
  - 엔진이 끔: `자동 종료 · 엔진이 자동전투를 껐습니다 · 패배`
  - 이벤트 없는 아군 행동: `자동 · <부대> 행동 완료 (대기 또는 혼란: 엔진 이벤트 없음)`
- **알려진 표시 한계**: 엔진은 3D 재생을 기다리지 않는다.
  - 자동 중 엔진은 적 슬롯이 끝나면 바로 다음 아군 자동 행동을 시작한다.
  - 그래서 3D의 적 재생이 다음 아군 행동 연출과 겹쳐 보일 수 있다(최종 위치와 표시 목록은 엔진과 같음).
  - 4배속에서는 더 촘촘하다. 엔진이 3D를 기다리게 하려면 엔진 쪽 연결점이 필요하다(범위 밖).
- 상태줄은 자동 중에도 적 재생·특기 문구로 계속 바뀐다. 마지막에는 결과 잠금 문구("전투 종료 · 패배 / 모든 입력 잠금")가 덮는다. 자동 문구는 전투 기록에 남는다.
