### 2-B. 단계별 판정 (각 단계마다 한 줄씩, 근거 코드 줄 번호 포함)
- ⓐ **미리 구울 수 있는가**: 입력이 고정(맵 데이터가 게임마다 같음)이고 출력이 메시·텍스처·`Resource`로 저장 가능한가. 저장 형식 후보(`.res`, `ArrayMesh`, `.tscn` 등)와 로드 시간 예상은 **측정한 값만** 쓴다(추정은 [추정] 표시).
- ⓑ **나눠 돌릴 수 있는가**: 스레드(`WorkerThreadPool`)·프레임 분산(`await get_tree().process_frame` 쪼개기)이 가능한가, 아니면 씬 트리 접근 때문에 메인 스레드에 묶이는가.
- ⓒ **줄일 수 있는가**: 해상도·정점 수·불필요 계산을 줄여도 화면이 같게 보이는가(김작 F6 판정이 필요한 항목은 "김작 확인 필요"로).
- ⓓ **체감만 바꾸는 방법**(로딩 화면·진행률 표시·2D 지도 먼저 보여주고 3D 교체)으로 시간 자체는 그대로여도 되는 단계가 있는가. 이미 있는 2D 지도로 즉시 시작하고 3D를 뒤에서 만드는 구조가 코드상 가능한지 [사실]로 확인(예: `set_map_view_3d`가 런타임 전환을 이미 지원하는가).
