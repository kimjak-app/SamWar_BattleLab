## 2. 바꾼 것
1. **가운데 자리 규칙** (`worldmap_hud_menu_router.gd`)
   - 왼쪽 = 상태 창, 오른쪽 = 도시 창, 가운데 = 메뉴 창 하나(`CityDetailPanel` 또는 팝업).
   - 팝업을 열면 도시 클릭으로 떠 있던 `CityDetailPanel`도 닫는다(전에는 남아서 둘이 같이 떴다).
   - 메뉴 창은 가운데 자리 오른쪽 위에 둔다. 높이는 내용만큼이고, 가운데 자리보다 길면 창 안에서 스크롤한다. 전에는 1280×720 교역 탭(638px)이 화면 밖으로 나갔고, 처음 도시를 누르면 창 높이가 1406px로 잡히기도 했다.
   - 스크롤은 창의 내용 노드를 `ScrollContainer` 안으로 옮겨서 만든다. main이 쥔 노드 참조는 그대로다.
   - 매 프레임 다시 맞춘다. 왼쪽 창을 끌어 옮기거나 내용이 바뀌어도 따라간다.
2. **주문 창은 무역 탭 자리를 교체** (7절)
   - 주문 창이나 자국무역 이송 창이 뜨면 `CityDetailPanel`을 숨기고 그 자리에 놓는다. 위에 겹쳐 띄우지 않는다.
   - '취소'나 '명령 저장'으로 닫히면 같은 도시의 무역 탭이 돌아온다.
   - 도시 행동 '교역'처럼 상단 메뉴 없이 주문 창이 열리면 교역 메뉴로 전환한다. 그래서 주문 창은 교역 메뉴에서만 뜬다(2-2).
3. **성 내부 그림** (`worldmap_city_interior_controller.gd`, 6절)
   - 그리는 층을 50에서 0으로 내렸다. 순서는 상단 바(40) ≥ 팝업(40) > 메뉴 창·주문 창(1, z 130) = 왼쪽·오른쪽 창(1) > 성 그림(0) > 3D 지도(-10)이고, 테크트리(60)는 그보다 위다.
   - 크기는 `WINDOW_WIDTH_RATIO` 0.307 → **0.20**, `MIN_WINDOW_WIDTH` 400 → **320**으로 바꿨다. 이 두 값만 바꿨고 나머지 배치 계산은 그대로다. 위치는 지금 자리(왼쪽 창 오른쪽, 위 맞춤)다.
   - 메뉴 창과 겹치면 메뉴가 열려 있는 동안만 접는다. 열린 도시는 유지하고, 접힌 동안은 Esc나 빈 지도 클릭을 받지 않는다. 메뉴를 닫으면 다시 편다. 겹치지 않으면 둘 다 보인다.
4. **'성 내부 보기' 버튼** (8절)
   - 오른쪽 도시 창의 **도시 이름 줄 오른쪽 끝**에 둔다. 창 높이를 늘리지 않으려고 그 자리를 골랐다. 버튼 줄을 따로 넣으면 1280×720에서 창이 화면 밖으로 39px 나갔다.
   - 내 도시이고 성 그림이 있는 도시일 때만 보인다. 대상 고르는 중이거나 모달이 열려 있는 등 CH-2 열기 조건이 안 맞으면 눌리지 않는다.
   - 누르면 열린다. 열려 있는 동안은 '성 내부 닫기'로 바뀌고, 누르면 닫힌다.
   - 도시를 클릭해도 그림은 열리지 않는다.
   - **다른 도시를 클릭하면 그림은 닫힌다.** 그 도시로 바꾸지 않는다. 바꾸면 버튼 없이 열리는 셈이기 때문이다.
5. **국가 창고 상태 글자 빼기** (7절, `worldmap_warehouse_tabs_controller.gd`): 1-4 표 첫 줄.
