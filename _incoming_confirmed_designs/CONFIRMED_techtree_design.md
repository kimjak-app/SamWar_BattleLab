# 삼국WAR 테크트리 확정 설계 v1.0

---

## 기본 원칙

```
도시 테크트리 = 태수 적성에 따라 자동 선택 + 플레이어 수동 투자 가능
국가 테크트리 = 재상이 실행, 플레이어가 방향 선택

자동 성장: 태수 임명 → 적성에 맞는 테크 자동 진행 (느리지만 꾸준)
수동 투자: 플레이어 직접 자원 투입 → 즉시 성장 (빠르지만 자원 소비)
```

---

## 태수 적성 타입

```
administrative (행정형) → 농업 테크 담당
economic (경제형)       → 상업 테크 담당
maritime (해양형)       → 어업 테크 담당 (희귀)
militaryAdmin (군정형)  → 군사 테크 담당
diplomatic (외교형)     → 무역·상업 연계

해양형(maritime) 보유 영웅 — 희귀:
한국: 장보고(해양 최고), 이순신(군정+해양)
중국: 주유(해양+외교), 여몽(해양+군정), 육손(해양+행정)
일본: 고니시 유키나가(해양)
```

## 1. 농업 테크트리

### 테크트리 구조
```
기초
└─ 농기구 개량
   → 조건: 없음
   → 비용: 철 100

   ├─ 관개수로
   │  → 조건: 농업 35 + 행정형 태수
   │  → 비용: 목재 300 + 철 150
   │
   │  ├─ 저수지
   │  │  → 조건: 관개수로 완료 + 인구 2만 +
   │  │          목재+철 보유
   │  │  → 비용: 목재 500 + 철 200
   │  │
   │  │  ├─ 이모작
   │  │  │  → 조건: 저수지 완료 +
   │  │  │          봄·가을 식량 잉여 3턴 연속
   │  │  │  → 비용: 금전 500 + 식량 200
   │  │  │
   │  │  │  └─ 대규모 농장
   │  │  │     → 조건: 이모작 완료 + 농업 80 +
   │  │  │             인구 3만 이상
   │  │  │     → 비용: 목재 500 + 철 300
   │  │  │
   │  │  │     └─ 곡창지대 ★최고
   │  │  │        → 조건: 대규모 농장 완료 +
   │  │  │                충성도 70 이상 +
   │  │  │                행정형 태수 5턴 유지
   │  │  │        → 비용: 목재 800 + 철 500 +
   │  │  │                금전 1000
   │  │  │
   │  │  └─ 수리시설
   │  │     → 조건: 저수지 완료 + 목재 보유
   │  │     → 비용: 목재 400 + 철 150
   │  │
   │  │     └─ 홍수 방어
   │  │        → 조건: 수리시설 완료 + 철 보유
   │  │        → 비용: 목재 300 + 철 200
   │  │
   │  └─ 비료 개발
   │     → 조건: 관개수로 완료 + 식량 잉여
   │     → 비용: 식량 300 + 금전 200
   │
   │     └─ 윤작법
   │        → 조건: 비료 개발 완료 + 농업 60
   │        → 비용: 식량 400 + 금전 300
   │
   │        └─ 집약농업
   │           → 조건: 윤작법 완료 + 인구 2만 +
   │                   행정형 태수
   │           → 비용: 금전 500 + 식량 500
   │
   └─ 목축업 (말 자원 보유 도시만)
      → 조건: 농업 30 + 말 자원 보유 도시
      → 비용: 식량 200 + 금전 100

      ├─ 목장
      │  → 조건: 목축업 완료 + 말 보유
      │  → 비용: 목재 200 + 금전 200
      │
      │  └─ 군마 육성 ★전투 연결
      │     → 조건: 목장 완료 + 철 보유 +
      │             군정형 태수
      │     → 비용: 철 300 + 금전 400
      │
      └─ 양잠 (비단 자원 보유 도시만)
         → 조건: 농업 40 + 비단 자원 보유 도시
         → 비용: 식량 200 + 금전 150

         └─ 직조공장 ★비단 생산
            → 조건: 양잠 완료 + 상업 50 이상 +
                    금전 잉여
            → 비용: 목재 300 + 금전 500
```

### 각 테크 효과
```
농기구 개량  → 농업 성장 속도 +10%
관개수로     → 쌀·보리 수확량 +15%
저수지       → 수확 안정 (가뭄 없음)
이모작       → 봄·가을 둘 다 수확
대규모 농장  → 수확량 +25%
곡창지대 ★  → 식량 잉여 극대화, 전국 공급 가능
수리시설     → 홍수 피해 감소
홍수 방어    → 홍수 피해 없음
비료 개발    → 농업 성장 속도 +15%
윤작법       → 매턴 소량 식량 추가
집약농업     → 적은 땅에서 최대 생산
목축업       → 말 생산 시작
목장         → 말 생산량 ↑
군마 육성 ★  → 기병 전투력 +20%
양잠         → 비단 생산 시작
직조공장 ★  → 비단 대량 생산
```

## 2. 상업 테크트리

### 테크트리 구조
```
기초
└─ 노점시장
   → 조건: 없음
   → 비용: 금전 100

   ├─ 상설시장
   │  → 조건: 상업 20 + 금전 잉여
   │  → 비용: 목재 200 + 금전 200
   │
   │  ├─ 대형시장
   │  │  → 조건: 상설시장 완료 + 상업 40 +
   │  │          인구 2만
   │  │  → 비용: 목재 300 + 금전 400
   │  │
   │  │  ├─ 화폐제도
   │  │  │  → 조건: 대형시장 완료 + 상업 55 +
   │  │  │          행정형 태수
   │  │  │  → 비용: 철 200 + 금전 600
   │  │  │
   │  │  │  └─ 조폐소 ★
   │  │  │     → 조건: 화폐제도 완료 + 상업 75 +
   │  │  │             충성도 60 이상 +
   │  │  │             경제형 태수 5턴 유지
   │  │  │     → 비용: 철 500 + 금전 1000
   │  │  │
   │  │  └─ 창고
   │  │     → 조건: 대형시장 완료 + 목재 보유
   │  │     → 비용: 목재 400 + 금전 300
   │  │
   │  │     └─ 대형창고
   │  │        → 조건: 창고 완료 + 상업 50
   │  │        → 비용: 목재 600 + 철 200 +
   │  │                금전 400
   │  │
   │  └─ 상단 조직
   │     → 조건: 상설시장 완료 + 상업 35 +
   │             외교형 태수
   │     → 비용: 금전 300 + 비단 100
   │
   │     └─ 대상단
   │        → 조건: 상단 조직 완료 + 상업 55 +
   │                보급 연결 인접 도시 2개 이상 +
   │                말 보유
   │        → 비용: 금전 500 + 비단 200
   │
   │        └─ 실크로드 ★
   │           → 조건: 대상단 완료 + 상업 75 +
   │                   외교형 태수 5턴 유지 +
   │                   동맹 세력 1개 이상
   │           → 비용: 금전 1000 + 비단 500 +
   │                   말 300
   │
   └─ 항구 (해안 도시만)
      → 조건: 상업 25 + 해안 도시 + 목재 보유
      → 비용: 목재 400 + 금전 300

      ├─ 무역선
      │  → 조건: 항구 완료 + 목재 충분 +
      │          해양형 or 외교형 태수
      │  → 비용: 목재 500 + 철 200 + 금전 400
      │
      │  └─ 무역항 ★
      │     → 조건: 무역선 완료 + 상업 70 +
      │             해양형 태수 +
      │             타국과 중립 이상
      │     → 비용: 목재 800 + 철 300 +
      │             금전 1000
      │
      └─ 조선소
         → 조건: 항구 완료 + 철 보유 + 목재 충분
         → 비용: 목재 600 + 철 400 + 금전 500

         └─ 대형조선소 ★전투 연결
            → 조건: 조선소 완료 + 철 500 +
                    해양형 태수
            → 비용: 목재 1000 + 철 600 +
                    금전 800
```

### 각 테크 효과
```
노점시장     → 금전 수입 +5%
상설시장     → 금전 수입 +10%
대형시장     → 금전 수입 +20%
화폐제도     → 세금 효율 +15%
조폐소 ★    → 금전 수입 극대화 + 전국 세금 효율 ↑
창고         → 자원 보관량 +20%
대형창고     → 자원 보관량 +40%
상단 조직    → 인접 도시 무역 수입 +10%
대상단       → 육상 무역 루트 추가 + 말 이동 효율 ↑
실크로드 ★  → 전국 무역 수입 극대화
항구         → 해상 무역 루트 개방
무역선       → 해상 무역 수입 +20%
무역항 ★    → 해상 무역 수입 극대화 + 루트 추가
조선소       → 수군 전투력 +15%
대형조선소 ★ → 수군 전투력 +30% + 거북선 해금 가능
```

## 3. 어업 테크트리 (해안 도시만)

### 테크트리 구조
```
기초
└─ 어촌 형성
   → 조건: 없음 (해안 도시만)
   → 비용: 목재 100 + 식량 50

   ├─ 연안 어업
   │  → 조건: 어업 20 + 목재 보유
   │  → 비용: 목재 200 + 금전 100
   │
   │  ├─ 어선단
   │  │  → 조건: 연안어업 완료 + 어업 35 +
   │  │          목재 충분 + 해양형 태수
   │  │  → 비용: 목재 400 + 철 100 + 금전 200
   │  │
   │  │  ├─ 원양어업
   │  │  │  → 조건: 어선단 완료 + 어업 55 +
   │  │  │          해양형 태수 + 소금 보유
   │  │  │  → 비용: 목재 600 + 철 200 +
   │  │  │          소금 200 + 금전 400
   │  │  │
   │  │  │  └─ 대어장 ★
   │  │  │     → 조건: 원양어업 완료 + 어업 75 +
   │  │  │             해양형 태수 5턴 유지 +
   │  │  │             소금 500
   │  │  │     → 비용: 목재 800 + 철 300 +
   │  │  │             소금 400 + 금전 800
   │  │  │
   │  │  └─ 어항 건설
   │  │     → 조건: 어선단 완료 + 목재 충분 +
   │  │             철 보유
   │  │     → 비용: 목재 500 + 철 300 + 금전 300
   │  │
   │  │     └─ 대형어항 ★전투 연결
   │  │        → 조건: 어항 완료 + 어업 65 +
   │  │                해양형 태수 + 조선소 보유
   │  │        → 비용: 목재 800 + 철 500 +
   │  │                금전 600
   │  │
   │  └─ 수산물 가공
   │     → 조건: 연안어업 완료 + 소금 보유 +
   │             어업 30
   │     → 비용: 소금 100 + 목재 200 + 금전 150
   │
   │     ├─ 건어물 생산
   │     │  → 조건: 수산물 가공 완료 + 소금 200 +
   │     │          어업 45
   │     │  → 비용: 소금 200 + 금전 200
   │     │
   │     │  └─ 건어물 보급기지 ★군사 연결
   │     │     → 조건: 건어물 완료 + 어업 65 +
   │     │             보급 연결 도시 2개 이상 +
   │     │             소금 400
   │     │     → 비용: 목재 400 + 소금 300 +
   │     │             금전 500
   │     │
   │     └─ 수산물 교역
   │        → 조건: 수산물 가공 완료 + 상업 30 +
   │                항구 보유
   │        → 비용: 금전 300 + 소금 150
   │
   │        └─ 해상 보급기지 ★
   │           → 조건: 수산물 교역 완료 +
   │                   건어물 보급기지 완료 +
   │                   해양형 태수 + 어업 80
   │           → 비용: 목재 600 + 소금 500 +
   │                   철 300 + 금전 800
   │
   └─ 염전
      → 조건: 어업 25 + 해안 도시 + 식량 보유
      → 비용: 목재 200 + 금전 150

      ├─ 대형 염전
      │  → 조건: 염전 완료 + 어업 40 +
      │          인구 1만 이상
      │  → 비용: 목재 400 + 금전 300
      │
      │  └─ 소금 창고
      │     → 조건: 대형 염전 완료 + 어업 55 +
      │             목재 충분
      │     → 비용: 목재 500 + 철 100 + 금전 400
      │
      │     └─ 소금 전매 ★
      │        → 조건: 소금 창고 완료 + 어업 75 +
      │                상업 50 이상 +
      │                경제형 or 외교형 태수
      │        → 비용: 금전 1000 + 비단 200
      │
      └─ 소금 보존법
         → 조건: 염전 완료 + 식량 잉여 +
                 행정형 태수
         → 비용: 소금 100 + 금전 200

         └─ 군량 보존 ★전투 연결
            → 조건: 소금 보존법 완료 + 어업 60 +
                    소금 300 + 군정형 태수
            → 비용: 소금 400 + 식량 300 +
                    금전 400
```

### 각 테크 효과
```
어촌 형성        → 수산물 생산 시작
연안 어업        → 수산물 +10%/턴
어선단           → 수산물 +20%/턴
원양어업         → 수산물 +35%/턴
대어장 ★         → 수산물 극대화 + 겨울 식량 걱정 없음
어항 건설        → 수군 정박 가능 + 무역 루트 ↑
대형어항 ★       → 수군 전투력 +20%
수산물 가공      → 수산물 보존 기간 ↑
건어물 생산      → 원정 식량으로 사용 가능
건어물 보급기지★  → 전시 보급 안정 + 원정 가능 거리 ↑
수산물 교역      → 타국과 수산물 무역 수입 ↑
해상 보급기지 ★  → 해상 원정 보급 완전 해결
염전             → 소금 생산 시작
대형 염전        → 소금 생산량 ↑
소금 창고        → 소금 비축량 극대화
소금 전매 ★      → 소금 독점 → 금전 수입 대폭 ↑
소금 보존법      → 식량 손실 감소
군량 보존 ★      → 전시 식량 손실 없음 + 원정 지속력 ↑
```

## 4. 군사 테크트리

### 테크트리 구조
```
기초
└─ 병영 설치
   → 조건: 없음
   → 비용: 목재 200 + 금전 100
```

## 테크트리 시간 제한 (확정 — 수치는 미확정)

### ① 건설 시간 (턴 소요)
```
자원 투입 즉시 착공 → N턴 후 완성
(자원만 있다고 즉시 완성 아님)

등급별 건설 시간:
기초 테크  → 3~5턴
중급 테크  → 8~10턴
고급 테크  → 15~20턴
최고 ★     → 25~30턴

※ 정확한 턴 수는 수입 기준 밸런싱 후 확정
```

### ② 국가 테크가 도시 테크를 잠근다
```
고급 도시 테크는 국가 테크 완료 없이 해금 불가

예시:
화폐 통일(국가) → 조폐소(도시) 해금
군사 개혁(국가) → 거북선·철갑보병(도시) 해금
동맹 체계(국가) → 실크로드(도시) 해금
병참 제도(국가) → 건어물 보급기지(도시) 해금

※ 전체 매핑은 별도 문서로
```

### ③ 자원 수입 속도 = 테크 템포
```
내정 잘 하면 → 자원 빨리 축적 → 테크 빨리 진행
내정 못 하면 → 자원 느리게 축적 → 테크 느려짐

핵심 딜레마:
자원을 테크에 쓰면 → 군사에 못 씀
자원을 군사에 쓰면 → 테크가 느려짐
자원을 모병에 쓰면 → 테크·군사 둘 다 느려짐

※ 전체 테크 비용 밸런싱은 별도 세션에서
```
