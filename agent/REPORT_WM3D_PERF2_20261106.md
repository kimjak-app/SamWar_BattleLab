## 6. 택한 해석·방법
- **측정 방법**
  - 세 지점을 임시 `git worktree`(클코드 스크래치패드, 작업 트리·가지와 무관)로 꺼냈고, import 캐시는 복사 후 재import했습니다(각 30초 안팎).
  - 측정기(`driver.gd`)와 임시 표식은 worktree 밖 스크립트와 worktree 안에서만 썼습니다. 측정 뒤 worktree를 지웠습니다. 방법 원문은 `perf2_method.txt`(로컬 경로는 가림)에 있습니다.
- **사용자 폴더**: 측정마다 `APPDATA`를 빈 임시 폴더로 바꿔 실행했습니다(지점·장면·모드마다 새 폴더, 1회째가 차가운 캐시). 김작 PC의 `user://`는 읽지도 쓰지도 않았습니다.
- 측정 중에는 다른 Godot 프로세스를 돌리지 않았습니다(60회를 하나씩 순서대로). 창 렌더는 회당 약 13초 창이 떴습니다.
- **창 렌더 = F6와 같은 디버그 실행**(편집기 바이너리 `--path`). 내장 프로파일러는 쓰지 않고 `Time.get_ticks_usec` 구간 계측으로 했습니다(지시서 2-A 4항의 대안).
- 05·06 지점에는 호스트 시작 표식을 넣을 수 없었습니다(그때 호스트 코드가 달라 패턴 없음). 그 지점은 측정기 기준(장면 전환 → 3D 루트 → 2프레임)과 루트 안 표식으로만 쪼갰습니다.
