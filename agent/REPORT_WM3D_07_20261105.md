## 택한 해석
- **`before_battle`은 `main.tree_exiting`에 걸되, main이 전투용 Engine 메타를 세운 경우에만 기록한다.** 메타는 `samwar_worldmap_battle_context`(main 150행 상수 `WORLDMAP_BATTLE_CONTEXT_META_KEY`, 6901행에서 설정)다. `tree_exiting`은 게임 종료·새 게임 화면 이동·테스트 정리 때도 오므로, 전투가 아닌 퇴장이 `before_battle`로 적히지 않게 했다. 메타 이름은 main 스크립트 상수표(`get_script_constant_map()`)에서 읽는다. main에서 이름이 바뀌면 호스트 테스트 9절이 실패한다.
- **`main.tree_exiting` 시점의 3D 레이어는 "해제 전·트리 밖"이다[사실, 호스트 테스트 9절].** 지시서 문구("3D 레이어가 아직 해제되지 않은 시점")대로 레이어와 3D 루트는 아직 유효한 객체다. 다만 Godot가 자식을 먼저 트리에서 빼므로 `is_inside_tree() = false`다. 메시·텍스처는 해제 전이라 VRAM 값이 남아 있을 것으로 [추정]하지만, 렌더 인스턴스가 장면에서 빠진 뒤라 값이 낮게 나올 수도 있다[미확인, 김작 PC CSV로 확인]. 더 이른 시점(메타가 서는 프레임)으로 옮기는 것은 08의 선택지로 남긴다.
