# EASTWAR 20x20 지형 단독 미리보기 안내 (F6 실행용 — 외형 2차 반영)

> **주의**: 새 텍스처·셰이더·스크립트 파일을 프로젝트에 복사한 뒤 처음 Godot 에디터를 열면 **초기 에셋 임포트(Import)에 수 분이 걸릴 수 있습니다.** 하단 임포트 진행 바가 끝날 때까지 잠시 기다려 주세요.

---

## 1. 실행 방법 (F6 단독 실행)
1. Godot 4.6 에디터에서 프로젝트를 엽니다.
2. 파일시스템(FileSystem) 독에서 **`res://scenes/battle3d/Terrain20x20_Preview.tscn`** 장면을 더블클릭해 엽니다.
3. 키보드 **`F6`** (현재 장면 실행 / Run Current Scene)을 누르면 전투 엔진·HUD 없이 20×20 3D 지형과 유닛 4기만 즉시 화면에 뜹니다.

---

## 2. 조작키 안내
- **`W / A / S / D` 또는 방향키**: 카메라 초점(Focus) 이동
- **마우스 휠 위/아래**: 직교 카메라 확대 / 축소 (`size` 18 ~ 85)
- **`Q / E`**: 카메라 90° 회전 (마우스 가운데 버튼 드래그로 자유 회전 가능)
- **`1`**: 정면 기본 시점
- **`2`**: 90° 회전 시점
- **`3`**: 강·5행 여울(Ford) 및 능선 클로즈업 시점
- **`T`**: 숲 칸 소나무 켜기 / 끄기 토글
- **`F`**: 숲 칸 나무 반투명(`alpha = 0.35`, 유닛 진입 시 가림 방지) 테스트 켜기 / 끄기 토글
- **`O`**: 선 밖 "그림 입힌 땅"(`outer_ground_tex`) 켜기 / 끄기 토글
- **`B`**: 통나무 목교(다리) 켜기 / 끄기 토글 (기본값 OFF: 5행 여울 모래톱 표시)
- **`F12`**: `../EASTWAR_C0C3_Evidence/` 폴더에 현재 화면 PNG 스크린샷 저장
