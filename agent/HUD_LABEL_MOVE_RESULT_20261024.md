## 0. 먼저 알릴 것 (2D/3D·지시와 다른 점)

1. **가운데 고정 폭(지시 예시의 "폭 700")은 쓰지 않았다.** 처음에 폭 700으로 HUD 아래 가운데(607..1307 × 126..)에 놓았더니, 승리 연습 [자동] 한 판에서 1프레임 겹침이 나왔다. 랩 왼쪽 정보 상자(평소 22..492)가 선택한 부대의 상태 목록 길이만큼 옆으로 늘어난다(측정: 상태 5개일 때 22..723). 그래서 다음 규칙으로 바꿨다.
   - 두 줄 모두 **글자 폭만큼만** 잡고, **HUD 가운데(x 957)에 맞춘다.** 위치는 HUD 틀 아래 6px(y 126)이고, 둘째 줄은 첫 줄 바로 아래(+2px)다.
   - 정보 상자가 라벨 밑까지 늘어나면 라벨을 **그 오른쪽 6px**로 비켜 놓는다. 정보 상자가 줄면 다시 가운데로 온다.
   - 셸은 라벨의 위치·크기·최소 폭만 바꾼다. 매 프레임 랩 처리 뒤(HUD 노드 `process_priority` 100)에 정한다. 랩 diff는 0이다.
2. 비켜서는 것은 1프레임 늦을 수 있다. Godot 컨테이너는 크기를 프레임 끝에 다시 맞추기 때문이다. 상자가 늘어난 그 프레임에는 셸이 아직 이전 폭을 본다. 측정한 판(승리 연습 [자동], 비켜선 프레임 2번)에서는 **겹친 프레임이 0**이었다. 1프레임 겹침이 생길 수 있는지는 원리상 가능하다고만 적는다.
3. 랩의 오른쪽 위 "대상/전투 기록" 상자는 1920×1080에서 화면 밖(x 3446)에 있다. 랩이 `PRESET_TOP_RIGHT` 뒤에 `position`을 다시 줘서 생기는 기존 동작이다. 이번 변경과 무관하고 고치지 않았다(랩 변경).
4. 라벨 글자는 그대로다("라운드 N · 아군/적 턴 · 행동 중: 부대", "라운드 N · 전투 종료", "기세 아군 N / 적 N · 메모").
