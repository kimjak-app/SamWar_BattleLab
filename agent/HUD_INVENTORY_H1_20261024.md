  - **"지금 행동 중인 적" 줄은 없다.** 적 행동자가 정해질 때(C:8169 `enemy_actor_selected`) 로그를 쓰지 않는다. 2D에서 지금 행동 중인 적은 로스터 카드의 금색 테두리로 보인다(`_get_production_roster_current_actor` C:16020).
- 3D의 "적 행동 중 · {id}"는 재생이 `enemy_actor_selected`에 닿을 때 상태 줄(`status`)에 쓰는 **현재 진행** 표시다(EP:819, 849-852). 유지 시간이 없어 다음 재생 글이 곧 덮는다. 계속 보이는 것은 T1으로 옮긴 `turn_label`의 "라운드 N · 적 턴 · 행동 중: {id}"다(EP:390).
- **결론 [사실]: 용도가 다르다.** 2D 로그 = 지나간 일 목록, 3D 줄 = 지금 누가 행동 중인지. 2D에서 3D 줄과 같은 용도는 로스터 금색 테두리다.

## 2-6. 김작이 정해야 할 것

1. 대응 표(2-3)의 줄마다: 대체 / 3D에만 있음(다듬기) / 새로 연결 중 어느 것으로 할지(표의 제안 그대로 갈지).
2. **로그 글의 출처**: 2D와 같은 글(엔진 `battle_log_lines`, 새 읽기 1개) / 랩 자체 기록(`combat_lines`, 새 읽기 0, 글이 2D와 다르고 적 줄은 재생 뒤에 나옴).
3. **"적 행동 중" 표시**: 2D처럼 로스터 금색 테두리로 할지, 3D 상태 줄을 2D 스타일로 다듬어 남길지, 둘 다인지. 용도가 2D 로그와 다르다(2-3 끝).
4. **옵션 상자(적 AI 하/중/상)의 자리**: 상단 명령 버튼과 겹친다. 버튼 아래로 내릴지, 다른 곳으로 옮길지.
5. **아군 쪽 왼편(로스터·현재 행동 장수·명령 패널)을 한 단계로 할지 둘로 나눌지.** 함께 옮기지 않으면 랩 정보 상자·행동 버튼과 겹친다.
6. 화면 밖에 있는 랩 대상/기록 상자: 로그 덩어리로 대체하고 그대로 둘지(지금도 안 보임), 화면 안으로 옮길지(T1 라벨 검사가 영향받음).
7. 새 읽기(초상·병종 아이콘·준비 아이콘·능력치·비용·로그 글·결과 이유)를 덩어리마다 허용할지. 지금 3D 읽기 목록에는 없다.
8. 후퇴(M7 보류)와 별도로, **2D 후퇴 버튼 처리기 2개가 서로 다르게 동작하는 것**(2-1)을 M7 때 정리할지.
