# CONFIRMED NATIONAL TECHTREE DESIGN

## Status
- Confirmed design lock for `v0.69-0 EASTWAR Strategic Simulation Foundation Roadmap Lock`.
- This document is design-only. No national tech tree data, UI, save/load, effects, economy, battle, diplomacy, or AI implementation is included in this task.

## Scope
- The national tech tree represents state-level strategic development.
- National tech should affect broad systems such as administration, logistics, recruitment, diplomacy, espionage, trade policy, and revolt control.
- National tech is separate from city tech. It should not replace local city development.

## Design Principles
- National tech should reinforce the EASTWAR strategic simulation foundation, not act as isolated passive bonuses.
- Tech effects should connect to public support, loyalty, security, trade, diplomacy, espionage, and military logistics only after each system has a stable MVP.
- Data structure should be introduced before UI polish.

## v0.69 Placement
- `v0.69-6 National Tech Tree Data MVP` is the first implementation step for this area.
- Final UX/UI is deferred to `v0.70-1 WorldMap Final UX/UI Information Architecture`.
