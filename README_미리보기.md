# EASTWAR 20x20 3D 지형 확인용 미리보기 장면 안내

> **⚠️ 중요 안내: 처음 프로젝트를 열면 에셋 임포트에 몇 분이 걸립니다**
> 지형 팩 텍스처(28장)와 3D 모델(`.glb`)을 Godot 4.6이 처음 불러올 때 `Importing assets...` 진행 창이 뜨면서 **1~3분가량 소요**될 수 있습니다. 에디터가 멈춘 것이 아니니 임포트가 끝날 때까지 잠시 기다려 주세요.

---

## 1. 실행 순서 (F6 한 번으로 바로 확인)

1. 앞서 전달된 지형 이식 압축 파일(`EASTWAR_20x20_Terrain_Port_Complete.zip`)과 이번 미리보기 압축 파일(`EASTWAR_Terrain20x20_Preview_Scene.zip`)을 모두 **`C:\dev\grok_terrain`** 폴더에 그대로 덮어씁니다.
2. **Godot 4.6 에디터**에서 `C:\dev\grok_terrain\project.godot` 프로젝트를 엽니다.
3. 첫 임포트가 완료될 때까지 기다립니다.
4. 왼쪽 아래 **FileSystem** 독에서 **`res://scenes/battle3d/Terrain20x20_Preview.tscn`** 파일을 더블클릭해 엽니다.
5. 키보드에서 **`F6`** (현재 장면 실행 / Run Current Scene)을 누릅니다.

---

## 2. 조작키 안내

| 키 / 입력 | 동작 설명 |
| :--- | :--- |
| **`W` / `A` / `S` / `D`** (또는 방향키) | 카메라 시점 수평 이동 |
| **`Q` / `E`** | 카메라 **90도 단위 회전** (`+90°` / `-90°`) |
| **마우스 휠 위/아래** | 화면 확대 / 축소 (`Zoom`) |
| **숫자 `1`** | **정면 기본 시점**으로 즉시 이동 (`yaw = 0.32`, `zoom = 60`) |
| **숫자 `2`** | **90도 회전 시점**으로 즉시 이동 (`yaw = 0.32 + 90°`, `zoom = 60`) |
| **숫자 `3`** | **강·여울(5행) 근처 클로즈업 시점**으로 즉시 이동 (`zoom = 32`) |
| **`T`** | **나무 켜기 / 끄기** 토글 (판 바깥 상징적 소나무 2군락 ON/OFF) |
| **`B`** | **통나무 다리 켜기 / 끄기** 토글 (`show_bridges` ON/OFF) |
| **`F12`** | 화면 캡처 저장 (`../EASTWAR_C0C3_Evidence/godot_preview_<PID>_<번호>.png`) |

---

## 3. 화면 왼쪽 위 상태 표시 항목

- `mountain_height_scale`: 전장 내부 산 능선 높이 배율 (기본값 `0.50`)
- `show_bridges`: 통나무 다리 표시 여부 (기본값 `OFF`, `B` 키로 전환)
- `scatter_inner_trees`: 전장 내부 칸 나무 배치 여부 (기본값 `OFF`)
- `나무 켜짐`: 배경 상징적 나무 군락 표시 여부 (기본값 `ON`, `T` 키로 전환)
