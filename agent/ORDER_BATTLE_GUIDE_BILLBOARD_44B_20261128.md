# 큐 44b: 전장 그림 밑그림(--guide)과 세운 그림(빌보드) 소품 레이어 — 12호 준비

기준 화면: 캡처 도구 카메라 B로 찍은 1920×1080 화면. 그림 땅(10호/12호) 위에 세운 2D 나무와 바위가 서 있고, 판 안팎의 강은 엔진 강 한 줄만 보인다.
합격 기준: 아래 4절 시험 통과(CI C-track 4/4). 기본값(옵션 끔)에서는 지금 전장 화면이 1픽셀도 바뀌지 않음(강물 애니메이션 제외, 큐 44와 같은 방법). 최종 판단은 12호 비교 캡처를 본 김작.

  - 땅 그림에 그린 나무가 바닥에 붙어 보였다(김작 지적, Drive 99).
- 김작 결정(Drive 100): 나무와 바위는 2D 그림을 세워서 올린다(PSST 시안 기준). 3D 모델은 예외로만 쓰고, 쓰기 전에 김작에게 먼저 묻는다.
- 둘레 선은 12호 비교 캡처를 본 뒤 김작이 정한다(Drive 98). 그래서 비교 캡처는 on과 off를 항상 둘 다 찍는다.

## 1. `--guide` (밑그림 출력)
- `tools/battle3d_capture.gd --guide --out <저장소 밖 폴더>`로 위에서 수직으로 내려다본 직교 PNG 두 장을 만든다. 창 모드에서만 실행한다(헤드리스는 종료 코드 2).
  - `guide_board_60m.png`: 판 안 0~60 m. 픽셀 좌표가 셰이더의 `board_paint_tex` UV(`v_world_pos.xz / 60`)와 정확히 같아야 한다. 해상도 2048×2048.
  - `guide_outer.png`: 판 밖. 셰이더 `outer_ground_tex`의 원점·크기·축 방향을 그대로 쓴다. `--outer-size 180`이면 180 m 기준. 해상도 2048×2048.
- 그리는 것은 엔진 데이터에서만 가져오고, 층마다 색을 따로 쓴다.
  - 강 마스크(물 표면)
  - 다리 양 끝
  - 높낮이 음영(등고선 또는 회색조)
  - 칸 경계
  - 숲 칸(FOREST)
  - 성과 성문 위치
  - 판 모서리 네 점
- 같은 이름의 `.json`을 남긴다. 들어갈 것: 원점, 크기(m), 축 방향(+x 오른쪽, +z 아래 등 실제 방향), 해상도, 층별 색 범례, 커밋 해시.
- 이 밑그림은 **작업용**이다. 최종 색 텍스처에 격자나 물줄기를 굽지 않는다(채비서 102).
- 시험 3에서 다리 양 끝과 판 모서리를 실제 캡처에 겹쳐 맞춰 본다.

## 2. 세운 그림 소품 레이어 (빌보드)
- `--paint <폴더>` 안에 `props.json`이 있으면 그 목록대로 2D 그림을 세워서 올린다. 없으면 아무것도 하지 않는다(기본 꺼짐).
  - 항목 형식: `{"image": "tree_a.png", "x": 12.5, "z": 30.0, "height_m": 4.0, "anchor": "bottom", "shadow": true}`. 좌표는 월드 m 단위다.
  - 카메라 쪽을 보도록 세운다(Y축 고정 빌보드). 밑동은 지형 높이에 붙인다. `anchor: bottom` 기준으로 지형을 샘플한다.
  - `shadow: true`이면 땅에 옅은 접지 그림자 원을 깐다.
  - 알파 컷아웃을 쓰고 깊이 정렬을 맞춘다. 부대보다 앞에 있으면 부대를 가린다.
- `--trees off`(이미 있는 옵션)는 기존 3D 나무만 끈다. 비교 캡처는 다음 조합으로 찍는다:
  - 3D 나무 켬 + 빌보드 끔
  - 3D 나무 끔 + 빌보드 켬
- 숲 칸(FOREST)의 실제 이동 판정은 바꾸지 않는다. 성문 앞 6칸도 그대로 둔다. 보이는 것만 바뀐다.
- 게임 장면(실제 전투)에는 아직 연결하지 않는다. 캡처 도구와 미리보기 장면에서만 쓴다. 게임에 넣는 건 12호를 보고 김작이 정한 뒤 별도 큐로 한다.

## 3. 시험 (`tests/scripts/test_battle3d_capture_options.gd`에 추가, 태그 `[BATTLE3D_CAPTURE]`)
1. 옵션을 모두 끈 기본값이 큐 44와 같다. 셰이더와 빌더 값, 장면 노드 수가 같아야 한다.
2. `--guide` 인자를 해석한다. 출력 이름 두 개와 `.json` 키가 맞아야 한다. 헤드리스로 실행하면 종료 코드 2.
3. 좌표 맞춤: 판 모서리 네 점과 다리 양 끝 월드 좌표를 guide 픽셀로 바꾼 값이 셰이더 UV 공식과 1픽셀 안에서 같다(계산으로 확인).
4. `props.json`:
   - 없으면 노드 0개.
   - 3개짜리 예제를 넣으면 노드 3개가 생기고, 밑동 높이가 지형 높이와 0.05 m 안에서 같다.
   - 잘못된 항목(이미지 없음, 좌표 범위 밖)은 건너뛰고 경고 한 줄을 남긴다.
5. 회귀: C-track 전체.
