## 0. 먼저 알릴 것

1. **[턴 종료] = 2D와 같은 엔진 함수다(연결함).** 확인한 사실:
   - 2D 상단 [턴 종료]는 `_end_ally_turn_by_wait`(C:6482)를 부른다. 이 함수는 **지금 행동 중인 아군(`active_unit_state`) 한 부대의 차례만 끝낸다.** 진영 턴 전체를 끝내는 함수가 아니다. 이름과 달리 2D [대기]와 같은 일이다.
   - 엔진 자신도 `active_unit_state == null`이면 아무것도 하지 않는다(C:6489-6490).
   - 랩 `request_wait`(EP:551)는 같은 엔진 함수를 같은 전제(행동 중 아군 있음)로 부른다. 그 앞에 표시용 거절(적 재생 중, 이미 행동함, 자동 중 등, EP:536-548)이 더 있다.
   - 실행으로 확인했다(새 시험):
     - 행동 중 아군이 있으면 클릭 1번에 엔진 쓰기 `_end_ally_turn_by_wait` 1개, 그 부대 행동 완료.
     - 행동 중 아군을 비우면(시험용 쓰기) 버튼이 비활성("대기 불가 · 먼저 아군을 선택하세요")이다. 랩도 엔진 쓰기를 보내지 않는다.
     - 같은 상태에서 엔진 함수를 직접 불러도 엔진 상태가 바뀌지 않는다.

   그래서 지시의 "다르면 비활성"에 해당하지 않아 `lab.request_wait()`에 연결했다. 랩에만 있는 표시용 거절(적 재생 중 등)은 2D에 없는 차이다.
2. **랩의 [대기] 버튼(행동 줄 24..664 × 254..292)은 그대로 두었다.** 지시는 "랩의 자동·턴 종료·속도 버튼을 비켜 둔다"이다. 그러나 랩의 [대기]는 공격·대기·방어·책략·특기 다섯 버튼 줄의 하나이고, 이 줄은 블록 4-2(부대 명령 패널)에서 함께 대체할 대상이다. 지금 빼면 줄 가운데가 빈다. 그래서 상단 [턴 종료]와 랩 [대기]가 같은 일을 하는 버튼으로 둘 다 보인다(→ 김작이 정할 것 1).
3. **[옵션]·[속도] 그림은 임시다(채코치 아트 필요).** 2D에 해당 그림이 없어서 단색 틀(바탕 짙은 갈색, 테두리 금색 2px, 모서리 10px)과 글자("옵션", "속도 ×1")로 만들었다. 2D 그림을 오리거나 흉내 내지 않았다.
4. 자동 켜짐/꺼짐 표시는 2D와 같게 **그림을 바꾸지 않는다.** 2D는 모든 상태에 같은 텍스처를 쓰고 툴팁만 "자동중지"/"자동전투"로 바꾼다. 켜짐 중에는 활성, 꺼짐 중에는 아군 명령이 가능할 때만 활성이다(`_refresh_auto_battle_button_state` C:6405-6413, RP:95-106). 켜짐 여부는 랩이 이미 읽는 `is_full_auto_battle_enabled`만 쓴다.
5. 후퇴는 그림만이다. 비활성, 처리기 연결 없음(눌림 신호에는 게임 전체 클릭 소리 `game_audio` 자동 연결 하나만 있음), 툴팁 "월드맵 연결 후 사용". 비활성 그림은 2D처럼 보통 그림과 같다. 2D 처리기 2개(RP:163-180, C:6152-6166)는 연결하지 않았다.
