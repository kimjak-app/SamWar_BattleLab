# 큐 46: 세력·장수 배치 A 수정안 + 게임 연결을 0.7 도로로 전환

기준 화면: `main` `60fd2a5`에서 F6로 새 게임을 시작한다. 월드맵 39성에 34세력이 A 수정안대로 깔리고, 163명이 각자 도시에 주둔한다. 3D 도로 표시와 실제 출전 가능 대상이 같아야 한다.
합격 기준: 아래 5절 시험이 모두 통과한다(CI C-track 4/4, WorldMap3D 성공). 새 게임과 저장 불러오기 둘 다에서 통과해야 한다. 최종 합격은 김작 F6다.

## 0. 근거
- 배치: 김작 11-28 08:52 "배치는 a 수정안" (Drive 67). 자료는 `data/heroes/source/placement_A_revised_20261128.json`이다. 39성, 34세력, 주둔 163명.
- 능력치: 김작 11-28 15:06 채팅 "Ok". 118명 명단 능력치 승인으로 받았다.
- 새 특기 9명: 김작 13:13, 기존 엔진 효과를 그대로 쓴다(Drive 83). 45b는 취소됐다.
- 0.7 도로: 큐 39 보고에 "기존 13성 게임 연결은 v2.4의 18개 그대로, 새 성 연결은 한쪽 방향만 있음 → 세력 배치 때 0.7로 전환"이라고 남아 있다. 0.7 데이터는 육로 100개, 바닷길 20개다.

## 1. 첫 커밋: 능력치 승인 표시
- 119명 정의의 `stats_approved`를 `true`로 바꾼다. 조운만 예외다. 조운은 `review_status`가 초안이므로 `false`로 남긴다.
- 커밋 메시지에 근거를 적는다: "김작 11-28 15:06".

## 2. 배치
- 위 JSON을 게임 시작 데이터로 연결한다. 설정할 것은 도시 소유 세력, 태수, 주둔 장수다.
  - 장수의 `assigned_city_id`, `city_id`, `location_city_id`를 채운다. 기존 seeder 경로를 쓴다(`worldmap_registered_hero_seeder.gd`).
  - 도시 이름을 도시 ID로 바꾸는 매핑표를 `data/heroes/source/`에 남긴다.
- 기존 13성의 도시 값(병력, 인구, 등급)은 바꾸지 않는다. 새 26성의 병력, 인구, 등급은 JSON 값을 쓴다. 이 값에는 `values_status: "proposal"`을 붙인다(자료의 '추가 검토' 표시를 그대로 이어 가는 것).
- 새 세력 ID는 JSON의 `faction_id`를 그대로 쓴다. `capital`도 JSON 값을 쓴다. 새 세력이 수도 없이 시작할 때 생기는 문제(승리 판정, AI, 창고)는 시험 7에서 확인한다.
- 무주공산으로 남는 성(65 − 39 = 26성)에는 장수를 넣지 않는다. 소유자는 ""으로 두고 기존 규칙(`WorldMapUnclaimedCityRules`)을 따른다.
- 같은 장수가 두 도시에 들어가면 안 된다. 그런 데이터가 있으면 시작할 때 오류로 멈추고 보고한다. 아무 도시나 골라 넣지 않는다.

## 3. 게임 연결을 0.7로 전환
- 출전, AI, 외교 거리, 첩보, 무역 경로 판정이 쓰는 게임 연결을 v2.4 18개에서 0.7 데이터(육로 100, 바닷길 20)로 바꾼다. 3D 표시가 이미 쓰고 있는 데이터와 같은 원본을 읽는다.
- 모든 연결은 양방향이다. 한쪽 방향만 있는 연결이 남으면 안 된다.
- 바닷길은 기존 수군 조건을 그대로 지킨다.
- 상도–평양, 상도–업성 직통처럼 0.7에 없는 옛 연결은 양방향 모두 없앤다.
- `worldmap_main.gd`를 바꿔야 하면 `tools/p1_exact_delta.py`에 새 체크포인트를 만들고, 이유를 보고서에 적는다.

## 4. 금지
- 규칙 값은 바꾸지 않는다: 전투 공식, 특기 수치, 가격, 충성도 규칙.
- 기존 44명의 능력치와 특기는 바꾸지 않는다. 바뀌는 것은 주둔 도시뿐이다.
- 예전 저장(A 이전)을 불러올 때 이미 진행된 소유나 장수 이동을 덮어쓰지 않는다. 덮어쓸지 말지는 정해지지 않았다. 예전 저장은 그대로 불러오고, 보고서에 "옛 저장은 옛 배치 유지"라고 적는다.
- force push와 브랜치 삭제는 하지 않는다.

## 5. 시험 (`tests/scripts/test_worldmap_placement_a.gd`, 태그 `[PLACEMENT_A]`, C-track 목록에 추가)
1. 새 게임:

   - 중복 배치가 0이다. 무주공산 26성에는 장수가 0명이다.
   - 34세력이 모두 존재하고, 각 세력은 성을 1개 이상 가진다.
2. 저장 후 불러오기: 수동 슬롯과 턴 체크포인트 모두에서 1과 같다.
3. 연결:
   - 게임 연결이 0.7 데이터와 똑같다(육로 100, 바닷길 20, 모두 양방향).
   - 상도–평양과 상도–업성 직통이 양방향 모두 없다.
   - 3D 도로 표시와 출전 판정이 쓰는 연결이 같다.
4. 첫 출전 대상(채비서 48, 72):
   - 34세력 각각에 대해 첫 턴에 출전할 수 있는 다른 세력 성이 1개 이상인지 표로 출력한다. 대상이 없는 세력은 실패다.
   - 하나뿐인 첫 길을 양방향으로 확인한다: **경주–고령, 상도–대도, 성도–라싸**.
   - 지도에서 이어진 것만이 아니라 실제 출전 판정(소유, 관계, 병력 조건)을 통과하는지 본다.
5. 바닷길: 수군 조건이 없는 세력은 바닷길로 출전하지 못하고, 있는 세력은 출전할 수 있다. 대표 한 쌍씩 확인한다.

7. 새 세력(수도 없음 포함): 턴 종료, AI 행동, 창고 표시, 승리 판정에서 오류가 없다.
8. 특기 9명(채비서 85): 실제 전투에서 기존 엔진 효과가 그대로 나오는지 확인한다.
