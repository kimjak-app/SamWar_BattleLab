# 삼국WAR 외교·첩보·반란 확정 설계 v1.0

---

## 1. 외교 시스템

### 기본 구조
```
관계 = 0~100 점수 + allied/neutral/hostile 상태
(기존 faction_relations 위에 점수 추가)

외교형 재상:
관계 개선 속도 +50%
동맹 유지 비용 -20%
수락률 +15%
거절 시 관계 하락 -5 완화
```

### 외교 행동

**① 조공 보내기**
```
비용: 금전 + 비단 소모
효과: 관계 점수 +15~25
쿨다운: 5턴
```

**② 무역 협정**
```
조건: 관계 점수 50 이상
효과: 특산물 거래 우대 비율 확정
```

**③ 동맹 제안**
```
조건: 관계 점수 70 이상
방식: 자원 패키지 제시
  금전·식량·비단·철·목재 조합으로 제시
  기간: 10턴 / 20턴 / 40턴 선택

수락 확률:
관계 점수 70 이상 → 기본 50%
관계 점수 50~70  → 기본 35%
관계 점수 50 미만 → 기본 15%

자원 보정:
상대 부족 자원 제시 (심각) → +40%
상대 부족 자원 제시 (중간) → +20%
상대 부족 자원 제시 (약간) → +10%
상대 남는 자원 제시        → +5%

기간 보정:
10턴 → 보정 없음
20턴 → 제시 자원 ×1.5 필요
40턴 → 제시 자원 ×2.5 필요

첩보 보정:
첩보로 자원 파악 완료 → 수락률 +15%
첩보 없이 제안       → 랜덤 (부족 자원 모름)

외교형 재상 보정:
수락률 +15%

최대 수락률: 90%
```

**④ 선전포고**
```
효과: 관계 점수 0 초기화 → hostile 전환
```

### 동맹 효과
```
무역 배수 ×1.25 → ×1.5로 강화
공동 침공 가능 (협공)
기술 일부 공유 (테크 해금 속도 ↑)
적 침공 시 군사 지원
```

### 동맹 군사 지원
```
지원 요청 수락 확률:
관계 점수 90 이상 → 수락률 90%
관계 점수 70~90  → 수락률 70%
관계 점수 70 미만 → 수락률 40%

외교형 재상 보정: 수락률 +15%
정치형 재상 보정: 수락률 +10%

거절 시 관계 점수 하락:
지원 요청 거절    → -20
반복 거절 (3회↑) → -40 + 동맹 파기 위험
자동 참전 거절    → -30
공동 침공 거절    → -10

외교형 재상 보정: 거절 시 하락폭 -5
정치형 재상 보정: 반복 거절 패널티 -10

자동 참전 옵션:
ON  → 동맹국 침공 시 자동 병력 파견
OFF → 매번 수락/거절 선택
```

### 국력 기준 (동맹 부담 비율)
```
국력 = 보유 도시 수×30 + 총 병력×0.1 + 총 자원량×0.05

국력 차이 0~20%  → 동등 (쌍방 동일 부담)
국력 차이 21~50% → 강대국 60% / 약소국 40%
국력 차이 51% ↑  → 강대국 70% / 약소국 30%
```

## 2. 첩보 시스템

### 기본 구조
```
첩보 주체: 재상 (정치형 적성)
장수 파견은 추후 추가 (현재 장수 부족)

재상 정치 적성별 성공률:
적성 5 → 80%
적성 4 → 65%
적성 3 → 50%
적성 2 → 35%
적성 1 → 20%
재상 없음 → 첩보 불가

정치형 재상 특혜:
발각 확률 전체 -10%
쿨다운 -2턴
```

### 첩보 방어
```
치안 + 국가 충성도로 방어:

치안 70 이상    → 발각 확률 +20%
치안 90 이상    → 발각 확률 +35%
충성도 70 이상  → 발각 확률 +15%
충성도 90 이상  → 발각 확률 +25%

치안 100 + 충성도 100 → 철옹성 (첩보 완전 차단)
```

### 정보 수집
```
재상 정치 적성별 파악 가능 정보:

적성 5 → 모든 정보
         (병력·자원·민심·충성도·태수·테크트리)
적성 4 → 대부분
         (병력·자원·민심·충성도)
적성 3 → 절반
         (병력·자원)
적성 2 → 일부
         (병력만)
적성 1 → 불확실
         (병력 대략적, 오차 있음)
```

### 첩보 행동

**① 민심 교란**
```
비용: 금전 300 + 쿨다운 8턴

재상 적성별 효과:
적성 5 → 민심 -20
적성 4 → 민심 -15
적성 3 → 민심 -10
적성 2 → 민심 -5
적성 1 → 민심 -3

발각 확률:
치안 50 미만 → 10%
치안 50~70  → 25%
치안 70~90  → 45%
치안 90↑   → 65%

발각 시: 관계 -30, 효과 없음
```

**② 충성도 교란**
```
비용: 금전 500 + 비단 50 + 쿨다운 10턴

재상 적성별 효과:
적성 5 → 충성도 -10 (다음 계절 반영)
적성 4 → 충성도 -7
적성 3 → 충성도 -5
적성 2 → 충성도 -3
적성 1 → 충성도 -1

발각 확률:
치안 50 미만 → 15%
치안 50~70  → 30%
치안 70~90  → 50%
치안 90↑   → 70%

발각 시: 관계 -40, 효과 없음
```

**③ 반란 조장**
```
비용: 금전 800 + 비단 100 + 쿨다운 15턴

전제 조건:
적 도시 민심 50 미만 AND 충성도 40 미만

재상 적성별 효과:
적성 5 → 반란 확률 +50% (3턴간)
적성 4 → 반란 확률 +35%
적성 3 → 반란 확률 +20%
적성 2 → 반란 확률 +10%
적성 1 → 반란 확률 +5%

발각 확률:
치안 50 미만 → 20%
치안 50~70  → 40%
치안 70~90  → 60%
치안 90↑   → 80%

발각 시: 관계 -60, 전쟁 선포 가능성 ↑
```

**④ 이간질**
```
비용: 금전 600 + 비단 150 + 쿨다운 12턴

전제 조건: 적이 동맹 보유 시만 가능

재상 적성별 효과:
적성 5 → 적 동맹 관계 -30
적성 4 → 적 동맹 관계 -20
적성 3 → 적 동맹 관계 -15
적성 2 → 적 동맹 관계 -10
적성 1 → 적 동맹 관계 -5

발각 확률:
치안 50 미만 → 15%
치안 50~70  → 35%
치안 70~90  → 55%
치안 90↑   → 75%

발각 시:
관계 -50
이간질 대상 동맹국도 알게 됨 → 나와의 관계 -20
```

**⑤ 암살**
```
비용: 금전 1000 + 비단 200 + 쿨다운 20턴

전제 조건: 첩보 조직 ★ 완료 필수

재상 적성별 성공률:
적성 5 → 40%
적성 4 → 30%
적성 3 → 20%
적성 2 → 10%
적성 1 → 5%

치안 보정:
치안 50 미만 → 성공률 +10%
치안 70↑    → 성공률 -15%
치안 90↑    → 성공률 -30%

결과:
성공 → 사망 50% / 부상 50%
실패 → 효과 없음
발각 → 관계 -80 + 전쟁 선포 거의 확실
```

### 공통 규칙
```
국가 충성도 방어 보정:
충성도 70↑ → 모든 발각 확률 +10%
충성도 90↑ → 모든 발각 확률 +20%

동일 도시 연속 시도:
연속 첩보 → 발각 확률 +20%

역첩보 알림:
발각 시 → "○○국의 첩보원을 잡았습니다" 표시
어느 나라인지 공개
관계 점수 자동 하락

첩보 결과 기록:
last_spy_result 저장
성공/실패/발각 여부 확인 가능
```

## 3. 반란 시스템

### 발생 조건
```
충성도 30 이하 AND 민심 30 이하 동시 충족
→ 반란 발생

경고 단계:
충성도 40 + 민심 40 이하 → 경고 (노란색)
충성도 30 + 민심 30 이하 → 위험 (빨간색) → 다음 턴 반란
```

### 진압
```
주둔군 + 장수 파견 → 진압 전투 발생

승리:
→ 반란 진압
→ 충성도 +10
→ 민심 +5

패배:
→ 해당 도시 주인없는 땅 (neutral)
→ 자원 생산 없음
→ 병력 없음
→ 누구든 먼저 점령하면 차지
→ 적국이 먼저 먹을 수도 있음
```

### 첩보 연동
```
반란 조장 성공 → 반란 확률 +50% (3턴간)
치안 100 + 충성도 100 → 반란 조장 불가 (철옹성)
```
